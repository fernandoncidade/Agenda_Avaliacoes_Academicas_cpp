Summary:
ACADEMIC EVALUATION SCHEDULE (AGENDA DE AVALIAÇÕES ACADÊMICAS) is a lightweight native Windows desktop utility engineered in C++23 with Qt 6.12.0 and local SQLite persistence. Its primary purpose is to consolidate, organize, and display the dates of assessment activities (exams, quizzes, assignments, seminars, presentations, etc.) for all courses enrolled during the semester in a single clear and accessible panel.

Main features:
- Structured assessment registration with cascading fields: Course, Syllabus, Semester, Subject, Class, Type of Assessment Activity, Activity Sequence, and Date.
- Persistent custom lists in listas.db automatically merged with built-in curricula (with Settings > Delete Item submenus for granular category removal).
- Consolidated chronological view sorted automatically by date (dd/MM/yyyy), with HTML escaping and individual or batch editing/deletion.
- Automatic subject color coding by course code/name ("Colorful" vs. "Black", saved in config.json).
- Direct PDF export (Qt PrintSupport / QPdfWriter) preserving chronological order and the selected color mode.
- Runtime bilingual interface switching between Português (pt_BR) and English (en_US) via Qt Linguist (.ts / .qm) and language.json.
- 100% Local-First and Offline architecture (%LOCALAPPDATA%\AgendaAvaliacoesAcademicas\): zero telemetry, zero external accounts, and clean uninstallation.
- Dual toolchain support across MSVC x64 (14.52.37025 / Windows SDK 10.0.28000.0) and MinGW-w64 x64 (GCC 15.1.0), ultra-clean external runtime distributions, app-local Inno Setup installers (without vc_redist.x64.exe), and modular CTest/QtTest verification suite.
